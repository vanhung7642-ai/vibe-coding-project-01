# vibe-coding-project-01
Hùng Vương Construction website

Corporate website structure, prepared for Vietnamese and English content.

- Root pages are Vietnamese; matching pages inside `/en/` are English.
- Shared styles and behavior live in `assets/css/style.css` and `assets/js/main.js`.
- All links use relative paths so the project works on GitHub Pages, including project subpaths.
- Placeholder copy is marked as `[Đang cập nhật]` / `[Content to be updated]` where official information is still required.

Main routes: `/`, `/about.html`, `/businesses.html`, `/projects.html`, `/capabilities.html`, `/news.html`, `/careers.html`, `/contact.html`.
